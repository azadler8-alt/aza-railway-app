# aza — سیستەمی پرچێس / فرۆشتن / مەغزەن / POS / حیسابات

سیستەمێکی پرۆفیشناڵی PHP + MySQL + HTML/CSS/JS (بەبێ فرەیمۆرک، ڕاستەوخۆ لەسەر Laragon کاردەکات).

## 1) دامەزراندن لەسەر Laragon

1. فۆلدەری `aza` بگوازەرەوە بۆ `C:\laragon\www\aza`
2. Laragon بکەرەوە و MySQL (و Apache) کارابکە.
3. لە phpMyAdmin (یان HeidiSQL) داتابەیسی `aza_db` دروست بکە، پاشان فایلی `database/aza_schema.sql` لەو database ـە import بکە.
4. پاش import، `ADMIN_PASSWORD=...` لە environment ـی PHP دابین بکە؛ لە یەکەم request ـدا هاشێکی دروست بۆ admin دروست دەکرێت.
5. بچۆ بۆ `http://aza.test/` و بە username ـی `admin` و ئەو password ـەی داناوتە چوونەژوورەوە بکە.
6. لە بەشی **IT → یوزەرەکان** یوزەری تری پێویستت (بەڕێوەبەر، کاشێر، هتد) دروست بکە و مۆڵەتی هەر بەشێکیان دیاری بکە.

> ئەگەر VirtualHost ت دروست نەکردووە، بەکاربردنی `http://localhost/aza/` باشترە. بۆ ئەوە فایلی `config/db.php` بگۆڕە: `define('BASE_URL', '/aza');`

## 2) بڵاوکردنەوە لە Railway

1. لە Railway project ـەکەتدا service ـێکی MySQL زیاد بکە.
2. ئەم repository ـە بە GitHub بۆ service ـێکی web deploy بکە. Railway بە خۆکار `Dockerfile` و `railway.toml` دەناسێت.
3. لە Variables ـی web service، reference ـی ئەم variable ـانە لە MySQL service دابین بکە:
  `MYSQLHOST`, `MYSQLPORT`, `MYSQLDATABASE`, `MYSQLUSER`, `MYSQLPASSWORD`
4. ئەم variable ـانەش زیاد بکە:
  - `ADMIN_PASSWORD`: وشەی نهێنییەکی بەهێز بۆ admin.
  - `BASE_URL`: بەتاڵی بهێڵەوە؛ لە Railway app خۆکارانە لە root کاردەکات.
5. لە MySQL service ـەکە، فایلی `database/aza_schema.sql` import بکە. پێش import دڵنیابە database ـی `MYSQLDATABASE` هەڵبژێردراوە.
6. لە Web service → Settings → Networking، `Generate Domain` بکە و `/health.php` تاقی بکەوە؛ دەبێت `ok` ببینیت.
7. پاشان domain ـەکە بکەرەوە و بە `admin` و `ADMIN_PASSWORD` بچۆ ژوورەوە.

> فایلەکە database دروست ناکات و `USE aza_db` بەکارناهێنێت؛ ئەمە وای لێدەکات لە database ـی Railway ـی خۆت بە دروستی import بکرێت.

## 3) پوختەی پێکهاتەی فۆلدەرەکان

```
aza/
  database/aza_schema.sql     -- سکیمای تەواوی داتابەیس
  config/db.php                -- ڕێکخستنی پەیوەندی + BASE_URL
  includes/                    -- auth, header, sidebar, footer, modules list
  assets/css, assets/js        -- دیزاین و JS گشتی
  index.php, logout.php, dashboard.php
  companies/    -- کۆمپانیاکان (لیست، دروستکردن، بینین، ڕەشکردنەوە)
  materials/    -- مادەکان (لیست، دروستکردن، بری هەبوون، کۆست، ڕاگیراوی فرۆشتن)
  purchase/     -- وەسڵی کرین (دروستکردن، ریکۆرد، پێداچوونەوە)
  warehouse/    -- مەغزەن (بەردەست + خەڵاسبوو)
  it/           -- یوزەرەکان + POS ەکان
  sales/        -- مەبیعات (راپۆرتی فرۆشتنی هەر کاشێرێک)
  accounting/   -- وەرگرتنی پارە، نەقس/زیاد، قەرزی شەریکە، مەسروفات
  pos/          -- شاشەی فرۆشتن + پسوولە
  reports/      -- قازانجی گشتی + قازانج بەپێی مادە
  Dockerfile    -- image ـی PHP بۆ Railway
```

## 4) خاڵە گرنگەکانی لۆجیک

- **P Number** لە وەسڵی کرین بەشێوەی خۆکار و بەبێ دووبارەبوونەوە دروستدەبێت (بەپێی ID ی خودی وەسڵ).
- **ئەڤەرێج کۆست**: هەر جارێک وەسڵی کرینی نوێ پاشەکەوت بکرێت، کۆستی مادە بەم دەستووره نوێدەبێتەوە:
  `کۆستی نوێ = ((کۆنی هەبوون × کۆستی کۆن) + (عددی نوێ × نرخی کرینی نوێ)) / کۆی عدد`
- **پێداچوونەوەی وەسڵی کرین**: کاتێک پێداچوونەوەی بۆ کرا، وەسڵەکە دەچێتە باری تەنها-خوێندنەوە. تەنها یوزەرێک کە مۆڵەتی `purchase_review` ی هەبێت دەتوانێ لایبباتەوە.
- **راگیراوی فرۆشتن**: کاتێک بری هەبوونی مادەیەک دەگاتە سفر یان کەمتر (بە فرۆشتن لە POS یان بە تەلەف لە بەشی بری هەبوون)، مادەکە خۆکارانە دەچێتە بەشی "ڕاگیراوی فرۆشتن" لەگەڵ هۆکار و بەروار.
- **مۆڵەتەکان**: بۆ هەر یوزەرێکی non-کاشێر، بۆ هەر بەشێک دەتوانرێت بە جیا "بینین" و "دەستکاری" چالاک/ناچالاک بکرێت. یوزەری کاشێر تەنها بەشی POS دەبینێت.
- یوزەرانی **admin** و **it** خۆکارانە هەموو بەشەکانیان بۆ کراوەیە.

## 5) پێشنیارە داهاتووەکان (پێویستی بە کارکردنی زیاترە)

- دەستکاریکردنی لاینەکانی وەسڵی کرین دوای پاشەکەوتکردن (ئێستا تەنها پێش پاشەکەوتکردن دەستکاریکردن هەیە، دوای ئەوە تەنها بینین/پێداچوونەوەیە).
- Export بۆ Excel/PDF بۆ راپۆرتەکان.
- بەشی وێنەی مادە دەتوانرێت بگوازرێتەوە بۆ CDN یان S3-compatible storage.
